# Самара 440 — интерактивный квест

Интерактивный образовательный веб-квест для индивидуального прохождения учащимися гимназии № 11, педагогами и родителями, посвящённый 440-летию Самары.

## Возможности

- 8 станций и 440 баллов;
- задания по истории, географии, культуре и космической промышленности Самары;
- премиальный визуальный стиль, фотографии Самары и логотип гимназии;
- встроенные авторские иллюстрации;
- адаптация для компьютеров и мобильных устройств;
- сохранение прогресса в браузере;
- именной сертификат для печати и скачивания;
- итоговая форма участника и отправка результата организатору через FormSubmit.

## Конфиденциальность

Данные итоговой формы отправляются организатору через сторонний сервис FormSubmit. Перед отправкой участник должен дать явное согласие. Репозиторий не хранит ответы участников.

## Запуск

Откройте `index.html` в браузере или используйте GitHub Pages.
